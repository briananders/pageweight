Privacy Policy for Pageweight

Last updated: November 27, 2026 · Published by Brian Anders

Summary

Pageweight does not collect, sell, share, or transmit any personal data, browsing history, or website inspection results to any remote server. Every measurement and report calculation happens strictly inside your local Chrome browser.

What Data the Extension Handles

When you explicitly click Analyze Page, Pageweight inspects the network resource metadata (asset URLs, MIME types, HTTP status codes, and transfer byte sizes) loaded by the active tab during that scan. Pageweight does not inspect form inputs, passwords, cookies, or page body text.

How Data Is Stored

  • Latest scan report: Held temporarily in browser session memory so the side panel remains populated while you work. It is never written to any external server and is automatically cleared when Chrome closes, or immediately when you click Clear Report.
  • Preferences and size budgets: Your optional size budgets and scan checkbox preferences (such as cache bypass and scrolling) are saved locally on your device only and are never synced or uploaded off-device.

No External Servers, Analytics, or Third-Party Services

Pageweight makes zero outbound network requests from its extension pages or background worker, enforces a strict Content Security Policy that blocks outbound connections, and contains no analytics, telemetry, advertising, or third-party SDKs.

Data Retention and User Controls

You can delete your current scan report at any time with the Clear Report button, clear saved size budgets with the Clear All button, or remove all local extension storage by uninstalling Pageweight from Chrome.

Changes to This Policy

If Pageweight's data handling practices ever change, this privacy policy will be updated before any new version is published.
